## 🧭 Правила работы (инструкции пользователя из прошлых сессий)

1. **Отвечать только на русском**, простыми словами, полными предложениями.
2. **Claude — только организатор.** Сам ничего не делает руками. Всю практическую работу
   (правка файлов, команды, запуск сервера, git) выполняет **через субагента Sonnet**
   (Agent tool, model: sonnet), затем **проверяет результат** и докладывает.
   Прямое чтение файлов для проверки — можно.
   Дословная установка пользователя: «Ты ничего сам не делаешь! Ты даёшь команду Сонет и проверяешь результат».
3. **Перед отправкой в браузерные консоли** — давать точный путь: URL + пункты меню + название кнопки. Не «найди X».
4. **Писать пользователю, что делаешь, и задавать вопросы — на русском.**
5. **Коммит/пуш в GitHub — только по явному «да» пользователя.** Сообщения коммитов
   заканчивать строкой `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

## 📦 О проекте

- Статический многоязычный маркетинговый сайт. Стек: чистый HTML/CSS/JS, **без сборщика**.
- Хостинг: **GitHub Pages** → https://japansystem595.github.io/system595-website/
- Репозиторий: **JapanSystem595/system595-website** (заглавные буквы; строчный URL — старый алиас с редиректом).
- Языки (9): en, ja, es, ru, de, uk, fr, hi, pt. Тексты и медиа — в `content.json`.

### Структура
- `index.html` — главная (hero + карточки-ссылки на разделы).
- Отдельные страницы: `about.html`, `devices.html`, `showrooms.html`,
  `studios.html` (Massage Studio Franchise), `moxi.html`, `software.html`, `partnership.html`.
- `layout.js` — единый источник шапки и подвала (инжектит их в плейсхолдеры на каждой странице).
- `script.js` — грузит `content.json`, применяет переводы (`data-i18n`), рендерит команду,
  устройства и карусели, управляет меню/языком/формой.
- `content.json` — все тексты по языкам + блок `_media` (фото/видео).
- `style.css` — стили.

### Источники контента (другие сайты пользователя)
- `japansystem595.com` (главная) → история о японском производстве на странице About.
- `system595.jp` (главная) → каталог товаров на странице Devices.
